How it works

One local router. Multiple free models. Zero cloud dependency. A small local model reads each task, decides which free provider is the right fit, and hands off execution — all without your code or files ever needing to leave your machine unless you choose otherwise.

⚙

Local Router

Gemma runs locally via Ollama, reading each task and deciding which free model handles it — nothing leaves your machine to route.

🧠

Free Model Stack

Gemini Flash, DeepSeek, and Qwen work together — each picked for what it's actually good at, at zero API cost.

🔒

Privacy by Design

Your code and files stay local by default. Only the minimum necessary leaves your machine, and only when you choose.

💸

$0 Cost

Built entirely on free tiers and open-weight models — no subscription, no metered API bill, ever.

BYOK

Wake-on-LAN

Sleep your laptop and wake it remotely to pick up queued tasks.

Sandboxed Execution

Automatic Failover

If one model fails a task, it's automatically handed off to the next.

Manual Escalation

Task History
